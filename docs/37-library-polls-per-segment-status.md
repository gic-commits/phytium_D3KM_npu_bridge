# 第八轮-30 ★库是"按段轮询状态"的；第 2 段状态=3 就是卡点

## 一、反汇编出的完整执行模型（已逐条验证）

`npu::VhaDnnImp::Execute` 的 lambda（0x1d3f8 起）：

```asm
1d3f8:  bl  VhaDnnTask::NextSegment()      ; 取"下一个段" → x20
1d404:  cbz x0, 1f394                      ; 取不到 → 跳出循环
1d408:  ldr x0, [x0]
1d410:  ldrh w0, [x0, #2]                  ; ★ 读**该段状态字段**的 u16
1d41c:  cmp w0,#0x4
1d420:  ccmp w0,#0x1,#0x4,ne               ; ★ 状态 ∈ {1,4} 才算"已完成"
1d424:  b.eq 1e008                         ; 已完成分支
1d428:  mov w0,#2 ; str [sp,#212]          ; 否则 status=2（未完成）
1d43c:  bl  VhaDnnTask::GetSubmitKey(w1)   ; 未完成 ⇒ 走"提交该段"路径
...
; 已完成分支 0x1e008：
1e018:  bl  VhaDnnTask::GetSlot()          ; 取本任务 slot
1e054:  mov w1, w23                        ; arg1 = slot
1e074:  bl  VhaObserver::HandleResponse(slot, cb, 0)   ; ← 等这条 slot 的响应
...
; 循环尾（段倒计数归零后）：
1dfa8:  subs w0,w0,#1 ; b.ne 1d3f8
1dfc0:  bl  VhaNotifyImp::Update(1)        ; 写状态（不 notify）
1dfcc:  bl  VhaDnnTask::Done::~Done()      ; ★ 触发 Signal ⇒ notify_all ⇒ 唤醒 WaitForCompletion
```

**⇒ 语义**：库**逐个段**检查其状态字段：
- 状态 ∈ {1,4} ⇒ 该段已完成 ⇒ 转去 `HandleResponse(slot)` **等这条响应**
- 否则 ⇒ 该段未完成 ⇒ 走 `GetSubmitKey` 路径**去提交该段**

## 二、★★★ gdb 实测到的段状态（决定性）

在 `0x1d414`（读完 `[x0+2]` 的下一句）断点，打印 `$w0`：

```
[09:21:00] 段状态#1 = 1   ★已完成
[09:21:00] 段状态#2 = 3   未完成      ← ★★★ 卡点就在这
[09:21:00] 段状态#3 = 1   ★已完成
[SUM] 读取次数=3 取值分布={1: 2, 3: 1}
```

**⇒ 第 2 段的段状态是 **3**，不属于 {1,4} ⇒ 库判定"该段未完成" ⇒ 进入提交路径 ⇒ 卡住。**
**⇒ 这就是"提交 3 次后停住"的直接机制。**

## 三、已排除：不是"响应条数不够"

推 96 条 / 254 条**同一键 `[+2]=1`** 的响应（`delay=50 + replay=30/80 + keep_slot=1`）：

```
提交=3  推送=96   库读=96    ⇒ 仍失败
提交=3  推送=254  库读=254   ⇒ 仍失败
```

**⇒ 库把 96/254 条全读走了，段状态仍然不变成 1/4 ⇒ 段状态**不是由响应队列设置的**。**

## 四、结论与下一步

**段状态字段的位置**：`NextSegment()` 返回段指针 → `ldr x0,[x0]`（段对象首成员）→ `[+2]`。
即状态存在**库为每个段维护的某个对象/缓冲**里，而该值**应由驱动或硬件在执行/完成时写入**（不是响应队列）。

**⇒ 下一步（精确）**：
1. 找出"谁写这个段状态字段"。它是 `VhaDnnTask::SetSegmentStatus` 之类，或**直接由驱动写入的映射内存**。
2. 观测到的取值 `1, 3, 1` 中，**3 很可能是"已提交/处理中"的中间态**；
   驱动需要把它推进到 **1 或 4**。
3. 检查我们的提交路径是否应向**某个每段的状态位**写入完成标记
   （可能是 CMDS 缓冲里的一段，或 MAP_BUF 出来的某个缓冲）。

**（这条线索比"响应键"精确得多：库的判定点、判定值、失败后果都已实测确认。）**
